## 维护建议

1. **定期清理**：每月检查 `exports/` 目录，删除过期导出包
2. **构建缓存**：PyInstaller 的 `dist/` 和 `build/` 目录在构建后可删除
3. **__pycache__**：Python 缓存文件可随时删除，会自动重建
4. **数据库备份**：定期备份 `server/database/qcc.db`
5. **虚拟环境**：`.venv/` 目录不要删除，如需重建可通过 `requirements.txt` 恢复
