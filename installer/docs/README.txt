QCC 离线测试工作台 - 使用说明
================================

版本: 1.1.0
日期: 2026-07-15

一、软件简介
-----------
QCC 离线测试工作台是一款独立运行的本地化测试执行平台，
专为无网络环境或网络安全要求严格的测试场景设计。

二、主要功能
-----------
1. 系统信息自动采集
2. 测试用例执行管理
3. 测试结果记录
4. HTML 报告生成
5. 结果包导出

三、使用方法
-----------
1. 启动程序
   - 双击桌面快捷方式
   - 或从开始菜单启动

2. 加载测试数据
   - 将测试包中的 TestData 文件夹复制到程序目录
   - 或在程序中指定测试数据路径

3. 执行测试
   - 点击"执行全部"批量执行
   - 或逐项点击执行

4. 查看结果
   - 测试完成后自动生成报告
   - 点击"导出结果包"保存结果

四、系统要求
-----------
- Windows 10/11 (64位)
- 管理员权限（部分功能需要）
- 100MB 可用磁盘空间

五、常见问题
-----------
Q: 程序无法启动？
A: 检查是否缺少 VC++ 运行时，下载安装即可。

Q: 如何更新测试计划？
A: 从 QCC 平台导出新的测试包，替换 TestData 目录。

Q: 结果如何导入平台？
A: 程序导出的 ZIP 文件可直接在 QCC 平台导入。
